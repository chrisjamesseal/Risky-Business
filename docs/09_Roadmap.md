# Roadmap

## Phase 1 — MVP

Single phone, offline, 2 to 8 players. Home / Pub / Club/Festival. Truths,
Dares, Challenges, Mini Games, Chaos Events. Scoreboard, Lifelines, Card editor,
Import/Export, Drink Mode, Pixel UI.

## Phase 1.1

Better balancing, better animations, smarter deck builder, statistics.

## Phase 1.5

Secret Missions, hold to reveal, mission tracking, mission completion prompt.

## Phase 2

Werewolf Mode — separate game. Roles: Werewolf, Villager, Orchestrator. Uses
Hold to Reveal.

## Phase 3

Cloud sync, community card packs, themes.

## Phase 4

AI generated cards, online features, more game modes.
