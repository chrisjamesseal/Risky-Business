# Scoring & Game Flow

## Point Values

| Difficulty | Points |
|------------|--------|
| Easy       | 100    |
| Medium     | 200    |
| Hard       | 300    |
| Extreme    | 500    |

## Failed Card

Awards zero points.

## Drink Mode

Off by default. No drinking during gameplay. At the end, players receive drinks
based on finishing position.

| Position | Drinks |
|----------|--------|
| 🥇 1st   | 0 🍺   |
| 🥈 2nd   | 2 🍺   |
| 🥉 3rd   | 4 🍺   |
| 4th+     | 6 🍺   |

## Winner

Highest score.
