# Gameplay

## Game Setup

1. Enter player names.
2. Choose location.
3. Choose Drink Mode.
4. Press Start.

## Locations

- 🏠 Home
- 🍺 Pub
- 🎵 Club/Festival

Each location has its own card pool.

## Objective

Earn the most points. Each player receives exactly five scoring turns. The
winner has the highest score.

## Turn Flow

1. Player's turn.
2. Reveal card.
3. Choose Complete or Swap Card (once per game).
4. Award points.
5. Next player.

## Lifelines

- **Swap Card** — available once. Draw another card.
- **Double Points** — available once. Activate before revealing a scoring card.
  The next scoring card is doubled.

## End Game

Display final leaderboard. If Drink Mode enabled, calculate and display final
drinks.
