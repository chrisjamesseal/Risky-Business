# Project Overview

## Purpose

Build an offline-first party game that combines truths, dares, mini games and
random events into one replayable experience.

The app is designed for one phone shared between all players.

Players compete to finish with the highest score after five scoring turns each.

Drink Mode is optional and only affects the final punishment after the game.

## Design Principles

- Simple
- Fast
- Funny
- Highly replayable
- Minimal setup
- Offline first
- Arcade pixel aesthetic

## Version 1 Goals

- Playable in under 30 seconds
- No accounts
- No internet
- Everything editable
