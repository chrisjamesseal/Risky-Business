# UI & UX

## Style

- Pixel arcade
- Bright colours
- High contrast
- Chunky buttons
- Pixel icons
- CRT inspired transitions
- Simple animations

## Navigation

Home → Player Setup → Game → Results → Home

## Gameplay Screen

- **Top:** Current player, current score, lifelines
- **Middle:** Large card
- **Bottom:** Persistent live leaderboard

## Leaderboard

Always visible. Updates with animations. Shows players sorted by score.

## Rules

- No progress bars.
- No turn counter.
- No unnecessary UI.
